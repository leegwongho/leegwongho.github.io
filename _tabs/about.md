# About

안녕하세요. FPGA Engineer입니다.

FPGA로 **network interface card(NIC)**를 설계하고 디버깅하는 일을 합니다. 개발하면서 배운 내용을 나중에 다시 읽고 도움을 얻을 수 있도록 기록합니다.

> 이 블로그에는 소속 회사의 정보(제품, 설계, 설정값, 측정 결과)를 싣지 않습니다. 개인 학습과 공개 자료를 기반으로 한 내용만 다룹니다.
