# Introduction

앞선 글에서 100G Ethernet의 구조와 개발 환경을 살펴보았습니다. 이번 글부터는 실제로 CMAC IP를 만들고 첫 Loopback을 시도했던 과정을 정리합니다.

> 당시 Vivado 프로젝트와 화면 캡처는 남아 있지 않습니다. 이 글의 설정 값은 기억을 바탕으로 정리한 것이며, 확신이 없는 값은 그렇게 표시했습니다.

---

# Goal

프로젝트 초반에 받은 첫 과제는 다음과 같았습니다.

- FPGA 내부 로직에서 **TPG(Test Pattern Generator)** 로 패킷을 생성한다.
- 이 패킷을 CMAC을 통해 **Loopback** 시켜 다시 수신한다.

CMAC IP를 처음 사용하는 단계였기 때문에, "MAC이니까 속도만 고르면 될 것"이라고 생각하고 시작했습니다.

---

# CMAC IP Configuration

처음 IP를 생성하면서 가장 당황했던 점은 **설정해야 할 항목이 생각보다 훨씬 많다**는 것이었습니다. 10G, 25G, 100G 같은 속도만 고르면 끝날 것이라고 예상했지만, 실제로는 Lane 구성, 클럭, FEC 등 Physical 쪽 설정까지 함께 결정해야 했습니다.

당시 선택했던 주요 설정은 아래와 같습니다.

| Item | Setting | Note |
|------|---------|------|
| Line Interface | CAUI-4 | 25G × 4 Lane |
| Core Clock | 약 322.265625 MHz|
| Reference Clock | 100 MHz |
| RS-FEC | 사용 안 함 | |


## CAUI-4

CAUI-4는 25Gbps Lane 4개로 100Gb Link를 구성하는 방식입니다. 003 글에서 설명한 QSFP28의 4 Lane 구조와 같은 방식입니다.

## Clock

CMAC은 사용자 로직과 연결되는 클럭, GT에 들어가는 참조 클럭, 초기화·제어용 클럭이 서로 다릅니다. 처음에는 이 클럭들의 역할이 구분되지 않아 어느 클럭이 어디에 연결되는지 이해하는 데 시간이 걸렸습니다.

## RS-FEC

이번 프로젝트에서는 RS-FEC를 사용하지 않도록 설정했습니다.

# First Loopback Attempt

IP 설정을 마친 뒤, TPG에서 만든 패킷을 CMAC으로 보내 Loopback으로 받아 보려 했습니다.

그런데 **직접 만든 패킷이 CMAC에서 외부로 출력되지 않았습니다.**

TPG에서는 패킷을 AXI4-Stream으로 보내고 있었고, 저는 데이터가 들어가면 MAC이 알아서 Ethernet 패킷으로 내보낼 것이라고 생각하고 있었습니다. 하지만 기대한 출력은 나오지 않았습니다.

cmac에서 출력으로 나오는 tready 제가 만든 tvalid와 임의이 데이터가 출력되고있음을 확인하였습니다. 처음엔 axi stream의 프로토콜에 이해가 잘못되었나 싶었었으나 아니었습니다.

지금 생각해 보면, 당시에는 Loopback 이후 RX 데이터가 들어오지 않는다는 사실에만 집중했습니다. 하지만 RX에서 데이터가 보이지 않는다고 해서 TX에서도 데이터가 전송되지 않았다고 단정할 수는 없습니다. TX 측의 실제 전송 여부를 먼저 확인했다면 문제를 다른 관점에서 접근할 수 있지 않았을까 하는 아쉬움이 남습니다.

---

# Searching for the Cause

원인을 찾기 위해 CMAC 데이터시트를 찾아보았습니다. 그리고 사수께 현재 상황을 설명하고 질문을 드렸습니다.

사수께서는 문제의 원인을 바로 알려주시는 대신 이렇게 말씀하셨습니다.

> 이더넷 프레임에 대해 먼저 공부해 보세요.

이 한마디가 이후 작업의 방향을 바꿨습니다. 저는 "패킷"이라는 말을 막연하게 쓰고 있었고, MAC이 어떤 형식의 데이터를 기대하는지 정확히 알지 못했습니다.

---

# What I Learned

- CMAC은 속도만 고르는 IP가 아니라, Lane 구성, 클럭, FEC까지 함께 정해야 하는 IP이다.
- "패킷을 만들어서 넣는다"는 말은 MAC이 기대하는 **프레임 형식을 알고 있을 때** 의미가 있다.
- 막혔을 때는 IP 설정을 반복해서 바꾸기 전에, 입력 데이터나, clk이 규격에 맞는지부터 확인해야 한다.
