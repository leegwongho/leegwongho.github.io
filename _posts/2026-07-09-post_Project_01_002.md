# Introduction

100G Ethernet Bring-up을 진행하기 위해서는 FPGA 보드뿐만 아니라 광 모듈, 트래픽 계측기, 개발 툴 등 다양한 환경이 필요합니다.

이번 글에서는 프로젝트에서 사용한 개발 환경을 소개하고, 각각의 장비가 어떤 역할을 수행하는지 설명합니다.

---

# System Configuration

전체 개발 환경은 아래와 같이 구성하였습니다.

```text
                +-----------------------+
                |      Vivado           |
                |  (Bitstream Download) |
                +-----------+-----------+
                            |
                         JTAG
                            |
                    +-------v--------+
                    |    VCU128      |
                    | Virtex US+ FPGA|
                    +-------+--------+
                            |
                        QSFP28
                            |
                    +-------v--------+
                    |    Spirent     |
                    | Traffic Generator|
                    +-----------------+
```

프로젝트는 VCU128 FPGA에서 CMAC IP를 동작시키고, Spirent Traffic Generator를 이용하여 실제 100Gb Ethernet 트래픽을 송수신하는 방식으로 진행하였습니다.

# Hardware

## Xilinx VCU128

VCU128은 Virtex UltraScale+ XCVU37P FPGA가 탑재된 평가 보드입니다.

본 프로젝트에서는 100G Ethernet CMAC IP를 구동하기 위한 플랫폼으로 사용하였습니다.

주요 특징은 다음과 같습니다.

- Virtex UltraScale+ FPGA
- GTY Transceiver 지원
- QSFP28 Connector 제공
- PCI Express 지원
- DDR4 Memory 탑재

100G Ethernet은 일반적인 FPGA I/O만으로는 구현할 수 없으며, 반드시 GT Transceiver를 사용해야 합니다.

VCU128은 이러한 GTY Transceiver를 기본 제공하기 때문에 100Gb Ethernet 개발에 적합한 플랫폼입니다.

---

## QSFP28 Optical Interface

100Gb Ethernet Link는 QSFP28 인터페이스를 통해 연결됩니다.

QSFP28은 하나의 모듈 내부에 4개의 고속 Lane을 포함하고 있으며, 일반적으로 Lane당 약 25Gbps 속도로 동작합니다.

```
25G
Lane0  \
25G      \
Lane1 -----> 100G Ethernet
25G      /
Lane2  /
25G
Lane3
```

CMAC IP 역시 내부적으로 4개의 GT Lane을 사용하여 하나의 100Gb Ethernet Link를 구성합니다.

---

## Spirent Traffic Generator

Ethernet Link의 정상 동작을 확인하기 위해 Spirent Traffic Generator를 사용하였습니다.

Spirent는 다음과 같은 기능을 제공합니다.

- Ethernet Packet 생성
- Packet 송신
- Packet 수신
- Throughput 측정
- Packet Loss 측정
- Latency 측정

프로젝트에서는 FPGA에서 송신한 패킷이 정상적으로 수신되는지, 반대로 Spirent에서 송신한 패킷이 FPGA로 정상 수신되는지를 검증하는 데 사용하였습니다.

# Software

## Vivado

Vivado는 FPGA 설계 및 구현을 위한 AMD(Xilinx)의 개발 도구입니다.

본 프로젝트에서는 다음 작업을 수행하였습니다.

- CMAC IP 생성
- GT 설정
- RTL Design
- Synthesis
- Implementation
- Bitstream 생성

또한 Hardware Manager를 이용하여 FPGA에 Bitstream을 다운로드하였습니다.

---

## Integrated Logic Analyzer (ILA)

FPGA 내부 신호를 실시간으로 확인하기 위해 ILA를 사용하였습니다.

Bring-up 과정에서는 다음 신호들을 중점적으로 확인하였습니다.

- stat_rx_aligned
- stat_rx_status
- stat_tx_status
- rx_axis_tvalid
- tx_axis_tready
- reset sequence

ILA는 Link가 올라오지 않는 문제를 분석하거나 Packet이 정상적으로 전달되는지 확인하는 데 매우 중요한 디버깅 도구였습니다.

프로젝트를 진행하면서 가장 많이 사용한 Vivado 기능 역시 ILA였습니다.
